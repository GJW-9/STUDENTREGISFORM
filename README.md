# Student REgistration Form
This is a simple school website where students can register by signing in after enrollment to secure themselves a spot in, getting them a StudentId and the likes, enabling them a seamless academic timeframe. 

## Features
-Sign-up form with ID Number, email, name and password.
-Validation: ID maust be 6-12 digits, email must contain @, name must be atleast 2 characters, passwoord must have 8+ -chararcters, a number and a capital letter.
-Enter button works only when all boxes are filled.
-confetti animation when form is submitted successfully.
-Personal welcome message that stays on screen

## Built with
-Javascript
-CSS
-HTML

## How to run
-Download or clone this repository.
-Open 'Registration.html' in a browser (or use the Live Server extension in VS Code).

## Files
-Registration.html: the page structure.
-Registration.css: the styling.
-Registration.js: welcome message and form validation.
-confetti.js: the confetti animation.
